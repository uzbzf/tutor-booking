# Tutor Booking System (Узбекистан & Онлайн)

Сервис онлайн-записи на уроки к репетитору и витрина обучающих курсов с трендовым дизайном 2026 года (Clean Neo-Minimalism / Glassmorphism), валютой **UZS (Узбекский сум)** и интеграцией платёжных систем **Click**, **Payme** и **Stripe**.

## Стек технологий
- **Фронтенд & Бэкенд**: Next.js 14+ (App Router), React 18, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons.
- **Валюта**: UZS (Узбекский сум / сўм).
- **Платёжные системы**:
  - 💳 **Click** (`my.click.uz`, Uzcard / Humo / Click Up QR)
  - 📱 **Payme** (`checkout.paycom.uz`, Uzcard / Humo / Payme QR)
  - 🌍 **Stripe** (Международные карты Visa / Mastercard, Apple Pay)
  - ⏳ Оплата после согласования / при встрече
- **База данных**: Локальная легковесная JSON-file БД (`data/bookings.json`) с автосохранением и автоматической инициализацией демонстрационных данных.

## Возможности

### 1. Клиентская витрина
- **Профиль репетитора**: аватар, регалии (МГУ, эксперт экзаменов), предметы, рейтинг 5.0 с модальным окном реальных отзывов.
- **Витрина авторских курсов**:
  - «Полный курс: Профильная математика» (1 800 000 UZS)
  - «Высшая математика для студентов» (1 400 000 UZS)
  - «Олимпиадная физика: От базы к победам» (2 400 000 UZS)
  - Покупка курса в 1 клик с выбором онлайн-оплаты через Click, Payme или Stripe.
- **Интерактивный 3-шаговый визард записи на уроки**:
  - Шаг 1: Выбор услуги (60 мин — 250 000 UZS, экспресс 30 мин — 150 000 UZS, пробник 90 мин — 350 000 UZS).
  - Шаг 2: Календарь и динамические временные слоты с учётом занятости.
  - Шаг 3: Данные ученика (поддержка номеров Узбекистана `+998...` и Telegram) + выбор способа оплаты (Click, Payme, Stripe, наличные).
- **Подтверждение и оплата**:
  - Экран успешной записи с деталями.
  - Модальное окно онлайн-оплаты с вкладками Click / Payme / Stripe, QR-кодами, ссылками на оплату и мгновенным подтверждением.
  - Кнопка выгрузки события в календарь (`.ics` для Google/Apple Calendar).

### 2. Панель администратора (`/admin`)
- Защита PIN-кодом `1234`.
- **Финансовая аналитика в UZS**:
  - Общий доход
  - Оплачено онлайн (выручка)
  - Ожидает оплаты
  - Записей на сегодня
  - Разбивка выручки по платёжным системам: **Click**, **Payme**, **Stripe**, **При встрече**.
- **CRM-таблица и фильтрация**:
  - Фильтры: «Все», «Уроки», «Курсы», «Оплачено», «Ожидает оплаты».
  - Живой поиск по имени, номеру телефона, курсу или теме.
  - Быстрая смена статуса оплаты (`Оплачено` ⟷ `Ожидает`).
  - Управление статусом занятия (Подтверждено, Проведено, Отменено) и удаление.
- **Переключатель режима**: «Клиент» ⟷ «Админка» в верхней навигации.

## Запуск проекта

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

Для запуска продакшн-сборки:
```bash
npm run build
npm run start
```
